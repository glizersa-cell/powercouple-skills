# Power Couple – סקילים ל-Claude ⚡

3 סקילים שאנחנו עובדים איתם כל יום בפאוור קאפל, מוכנים להטמעה אצל כל אחד מהצוות:

| סקיל | מה הוא עושה |
|---|---|
| **pc-email** | ניסוח ושליחת מיילים בסגנון שלנו – תיקים לבנקים, מסמכים ללקוחות, נסחי טאבו, הסכמים. כולל כללי ברזל (טיוטה קודם, PDF בלבד, פיצול תיקים גדולים). |
| **pc-social-proof** | הפקת תמונות הוכחה חברתית: סטורי "חתמו!" ללקוח (1080x1920), וקולאז׳ צילומי מסך עם טשטוש שמות (תשלומים, ביט, הודעות). |
| **pc-video-captions** | תמלול סרטון בעברית (Groq Whisper) + צריבת כתוביות מעוצבות לסטורי/רילס, ודחיסה לוואטסאפ. |

## התקנה מהירה – Claude Code (מומלץ, הכל עובד כולל סקריפטים)
פותחים טרמינל ומדביקים:
```bash
git clone https://github.com/glizersa-cell/powercouple-skills.git ~/powercouple-skills && bash ~/powercouple-skills/install.sh
```
או פשוט כותבים ל-Claude Code:
> תתקין לי את הסקילים מ-https://github.com/glizersa-cell/powercouple-skills

**דרישות:** Node.js 18+, ffmpeg, Google Chrome (לתמונות ולכתוביות). מפתח Groq חינמי לתמלול (console.groq.com → API Keys) במשתנה `GROQ_API_KEY`.

## התקנה ב-claude.ai (אפליקציה / דפדפן)
1. מורידים את הריפו כ-ZIP (Code → Download ZIP) ופותחים.
2. מכווצים כל תיקייה בתוך `skills/` לקובץ ZIP נפרד (למשל `pc-email.zip`).
3. ב-claude.ai: Settings → Capabilities → Skills → Upload skill → מעלים כל ZIP.
> ב-claude.ai הסקילים עובדים בעיקר כ"הוראות": ניסוח מיילים (עם מחבר Gmail – יוצר טיוטות), מבנה תמונות ותסריטים. הסקריפטים (Chrome/ffmpeg) רצים מלא רק ב-Claude Code.

## כללים שחלים על כל הסקילים
- **שום דבר לא יוצא החוצה בלי אישור מפורש** – מייל, פרסום, הודעה ללקוח. ברירת מחדל: טיוטה + תצוגה.
- **פרטיות לקוחות:** בלי ת״ז, מספרי חשבון, חתימות או שמות בצילומים ציבוריים. מחיר מהסכם – רק באישור הלקוח.
- אין בריפו סודות. סיסמאות ומפתחות נשמרים רק במחשב שלך (`~/.config/powercouple/`).
