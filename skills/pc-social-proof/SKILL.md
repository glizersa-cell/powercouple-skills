# הוכחות חברתיות – פאוור קאפל

הכלים בתיקייה `scripts/` (פעם ראשונה: `cd ~/.claude/skills/pc-social-proof/scripts && npm install`). צריך Google Chrome מותקן (או `CHROME_PATH`).

## 1. סטורי "חתמו!" ללקוח – `story.mjs`
יוצרים קובץ JSON (מערך, סטורי לכל לקוח) ומריצים:
```bash
node story.mjs stories.json out/
```
```json
[{
  "name": "דנה ויוסי",            "type": "עסקת אופציה",
  "price": "1,370,000",           "photo": "/path/client.jpg",
  "crop": "/path/price-clause.jpg", "comp": "/path/project.jpg", "compLabel": "שדרות ירושלים, קריית ים",
  "bullets": ["דירת 4 חדרים חדשה מקבלן", "שדרות ירושלים, קריית ים", "נכנסו באופציה – בלי משכנתא עד המימוש"],
  "cta": "רוצים להיות הבאים? <b>שלחו \"דירה\" בהודעה</b> 👇", "logo": "/path/logo.png"
}]
```
**מאיפה החומרים:**
- `photo` – תמונת הלקוח (כבר סטורי עם כיתוב? לא לחתוך – היא מוצגת ב-contain).
- `crop` – **רק שורת המחיר** מהסכם הרכישה (סעיף "התמורה" / "מחיר המימוש" בהסכם אופציה). להמיר את העמוד לתמונה, לחתוך רק את השורה – **בלי ת״ז, שמות צד ג׳, חשבונות בנק או חתימות**. לבדוק כל חיתוך בעין.
- `comp` – הדמיה של הפרויקט; אם אין, צילום אוויר של העיר (ולציין זאת).
- `type`: עסקת אופציה / יד 2 / פינוי בינוי / שליש / "עסקה שנייה 🔁" ללקוח חוזר.
- ⚠️ לפני פרסום – לוודא שהלקוח אישר לפרסם את המחיר והתמונה.

## 2. צילומי מסך עם שמות מטושטשים – `blur.mjs`
למשל: "אנשים משלמים על הפגישה 500 ₪ ביום-יום" (צילומי ביט), הודעות תודה מלקוחות.
```bash
node blur.mjs blur.json out/proof.png
```
```json
{ "width": 1320, "rowHeight": 205, "columns": 1,
  "rows": [
    { "src": "/path/shot1.jpg", "top": 276, "blur": [[170, 8, 640, 76]] },
    { "src": "/path/shot2.jpg", "top": 34,  "blur": [[170, 8, 640, 140]] }
  ] }
```
- כל `row` = רצועה מצילום מסך: `top` = הפיקסל שבו מתחילה השורה בצילום; `blur` = מלבנים לטשטוש `[right, top, width, height]` יחסית לשורה (right = מרחק מהקצה הימני – נוח לעברית).
- **איך מוצאים קואורדינטות:** לפתוח את צילום המסך (Read) – הקואורדינטות שרואים הן בפיקסלים של התמונה. שורת ביט טיפוסית (רוחב 1320): שם בגובה ~0–76 מתחילת השורה, תיאור ~76–140, תאריך מתחת.
- לבחור רק שורות שמוכיחות את המסר (למשל רק תשלומים של 500 ₪; בלי זיכויים/סכומים אחרים שמבלבלים).
- לטשטש גם תיאור שמכיל שם ("פגישת אפיון <שם>").
- להוסיף מתחת לתמונה בדף: "השמות טושטשו לשמירה על פרטיות הלקוחות".
- בדף מכירה: 2 תמונות זו לצד זו בדסקטופ, אחת מתחת לשנייה במובייל (שהטקסט יהיה קריא).

## טון הכיתובים (מותג פאוור קאפל)
עברית יומיומית, "אנחנו", נועז, מספרים אמיתיים, בלי הבטחת רווח. דוגמאות: "זה לא ״מבצע בכאילו״!", "לא סיפורים. חתימות.", "רוצים להיות הבאים?".
צבעים: כחול כהה ‎#0A1633, כחול ‎#1F5BFF, צהוב ‎#FFD23F, ירוק ‎#3FD07A · פונט Heebo.

## לפני שליחה
להראות תצוגה (לפתוח את ה-PNG עם Read ולבדוק שאין פרט מזהה שנשאר גלוי), ורק אז למסור למשתמש. לא לפרסם בעצמך.
