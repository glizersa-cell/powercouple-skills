# כתוביות ועריכת סרטונים – פאוור קאפל

דרישות: `ffmpeg`, Google Chrome, Node 18+. פעם ראשונה: `cd ~/.claude/skills/pc-video-captions/scripts && npm install`.
מפתח Groq (חינמי, console.groq.com) – במשתנה `GROQ_API_KEY` או בקובץ `~/.config/powercouple/groq-key`.

## תהליך
1. **תמלול:**
   ```bash
   node transcribe.mjs video.mp4 asr.json "הקשר קצר: מי מדבר ועל מה + שמות/מונחים (פינוי בינוי, קריית ים, …)"
   ```
   מדפיס את הסגמנטים עם זמנים. ה-prompt משפר מאוד דיוק של שמות ומונחים.
2. **לבדוק את התמלול** ולהראות למשתמש שורות חשודות (שמות, מספרים). תיקונים נותנים בקובץ `fix.json` – מילה שגויה → נכונה:
   `{ "בקם,": "בקהאם,", "קרית": "קריית" }`
3. **צריבת כתוביות:**
   ```bash
   node captions.mjs video.mp4 asr.json out.mp4 [--fix fix.json] [--words 3] [--pos 0.67] [--size 50]
   ```
   - עד 3 מילים בכתובית (חותך גם בפיסוק ובשתיקה מעל 0.6 שנ׳), כל כתובית נשארת עד הבאה (מקס׳ +0.6 שנ׳).
   - `--pos` = גובה הכתובית כחלק מגובה הווידאו (0.67 = שליש תחתון, טוב לסטורי; 0.5 = אמצע, טוב לרילס עם טקסט למעלה).
   - האודיו מועתק כמו שהוא; וידאו x264 CRF 20.
4. **לבדוק:** לחלץ 3–4 פריימים ולפתוח עם Read:
   `ffmpeg -ss 5 -i out.mp4 -frames:v 1 check.jpg`
5. **מסירה:** קובץ מעל ~60MB → דחיסה לוואטסאפ:
   `ffmpeg -i out.mp4 -c:v libx264 -crf 23 -maxrate 8M -bufsize 16M -c:a aac -b:a 160k -movflags +faststart out-wa.mp4`

## עוד עריכות נפוצות (ffmpeg)
- חיתוך: `ffmpeg -ss 00:00:03 -to 00:00:52.6 -i in.mp4 -c:v libx264 -crf 20 -c:a aac out.mp4`
- 9:16 מסרטון רוחבי (מרכז): `-vf "crop=ih*9/16:ih,scale=1080:1920"`
- גיליון פריימים לסקירה מהירה: `ffmpeg -i in.mp4 -vf "fps=1/2,scale=180:-1,tile=8x5" -frames:v 1 sheet.jpg`
- הוספת לוגו בפינה: `-i logo.png -filter_complex "[1]scale=180:-1[l];[0][l]overlay=W-w-40:40"`

## סגנון פאוור קאפל לסרטונים
- כתוביות לבנות, Heebo 900, רקע שחור 62% מעוגל – קריא על כל רקע.
- מחירים מהסכמים – בלי שמות לקוחות. בלי הבטחת רווח ("פער", "אינדיקטור").
- הוק ב-3 השניות הראשונות, CTA בסוף ("הלינק בביו" / "שלחו 'דירה'").
