# מיילים בסגנון פאוור קאפל

## כללי ברזל
1. **טיוטה קודם.** תמיד מציגים את הנוסח המלא + מאיזה חשבון + למי + אילו קבצים, ושולחים רק אחרי "כן/שלח" מפורש.
2. **קבצים רק PDF.** לא צילומי מסך, לא תמונות, ובמיוחד לא קובצי ‎.xls שהבנק ייצא (הם בעצם HTML – מערכות האבטחה של הבנקים חוסמות אותם).
3. **תיק גדול (מעל ~8 קבצים) → לפצל לשני מיילים:** "(1/2): מסמכים אישיים ועסקיים" ו-"(2/2): מסמכי בנק". אחרי השליחה – לעדכן את הבנקאי/ת בוואטסאפ שהתיק נשלח.
4. **שמות קבצים ברורים:** `<שם לקוח> - <סוג מסמך>.pdf` (למשל "ישראל ישראלי - עו״ש.pdf").
5. **פרטיות:** לא לשלוח מסמכים של לקוח אחד ללקוח אחר. אחרי השליחה למחוק עותקים מקומיים של מסמכים רגישים.
6. **מכתבים ללקוח** חתומים "דין ומיק, פאוור קאפל". מיילים לבנקים – "בברכה, פאוור קאפל".

## תבניות

### לקוח חדש לבנק (בדיקת מימון)
**נושא:** `לקוח חדש: <שם מלא> – מסמכים לבדיקה`
```
היי <שם הבנקאי/ת>,
מצרפים את התיק של הלקוח <שם> לבדיקה.
*בקצרה:* בן/בת <גיל>, <מצב משפחתי>, <עיר>. <שכיר/עצמאי – תחום, ותק>. בנק: <הבנק של הלקוח>. <הלוואות פעילות / אין>.
*מסמכים מצורפים:*
• שאלון פיננסי
• תעודת זהות + ספח
• 3 תלושי שכר אחרונים / שומה + רווח והפסד (לעצמאי)
• עו״ש 3 חודשים אחרונים
• ריכוז יתרות
• ריכוז הלוואות
נשמח לבדיקה ולעדכון.
בברכה,
פאוור קאפל
```
- עצמאי – במקום תלושים: שומת מס אחרונה + דוח רווח והפסד מרו״ח לשנה השוטפת + אישור מחזור.
- תיק מעודכן ללקוח קיים: נושא `לקוח: <שם> – תיק מעודכן לבדיקה (<נכס>)` + משפט על העסקה שחתם.

### מסמך ללקוח (הסכם / נסח / פירוט)
**נושא:** `<סוג המסמך> – <כתובת הנכס>` (למשל "נסח טאבו – נרשמה הערת אזהרה לטובתך | <רחוב מס׳, עיר>")
```
היי <שם פרטי>,

מצורף <המסמך> של הדירה שקנית ב<כתובת>.
<משפט אחד שמסביר מה זה אומר עבורו – למשל: נרשמה הערת אזהרה לטובתך ולטובת השותפים ✅ היא מבטיחה את הזכויות שלכם בדירה עד להשלמת הרישום.>

לכל שאלה – אנחנו כאן.

בברכה,
דין ומיק
פאוור קאפל
```

## איך שולחים בפועל

### Claude Code – סקריפט SMTP (Gmail / Google Workspace)
הגדרה חד-פעמית: בחשבון Google → אבטחה → אימות דו-שלבי → "סיסמאות אפליקציה" → ליצור סיסמה. לשמור בקובץ
`~/.config/powercouple/mail.json`:
```json
{ "office": { "user": "office@powercouple.co.il", "pass": "xxxx xxxx xxxx xxxx", "name": "פאוור קאפל" } }
```
(אפשר כמה חשבונות. הקובץ נשאר רק במחשב – לעולם לא להדביק סיסמאות בצ׳אט או בריפו.)

```bash
cd ~/.claude/skills/pc-email/scripts && npm install   # פעם ראשונה בלבד
node send.mjs --from office --to a@b.co.il[,c@d.co.il] [--cc …] --subject "…" --body-file body.txt \
  --attach "/path/a.pdf" --attach "/path/b.pdf" [--dry]
```
- `--dry` – מציג מה יישלח (נמענים, נושא, קבצים וגודל) בלי לשלוח. **להריץ קודם עם --dry ולהראות למשתמש.**
- הסקריפט מסרב לשלוח קבצי xls/xlsx/html ומזהיר מעל 10 קבצים או 15MB.
- גוף המייל: טקסט רגיל; `*מודגש*` הופך להדגשה ב-HTML.

### claude.ai – מחבר Gmail
אם מחובר Gmail: ליצור **טיוטה** עם הנוסח והנמענים, ולהגיד למשתמש לצרף את קובצי ה-PDF ולשלוח מהג׳ימייל (המחבר לא תמיד תומך בקבצים מצורפים).
